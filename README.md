# Super Creeper Bros 8-Bit

Enhanced HTML5 Canvas Platformer.

Play the Creeper, jump on the Zombie, collect diamonds, and reach the portal to save the village!

## How to Play

1. Clone or download this repo
2. Open `index.html` in any modern browser
3. Controls:
   - Move: Arrow keys or A/D
   - Jump: Space / W / Up Arrow
   - Run + Boost Jump: Hold SHIFT or Right Click
   - Restart: R (when game over or win)

## Features

- Smooth acceleration and friction
- Full AABB platform collisions (sides + top/bottom)
- Zombie with gravity and patrol
- Web Audio sound effects
- LocalStorage high score
- Pixel-perfect 8-bit style drawing
- Camera follow
- Game Over and Win screens
